# Personal Identity Card using Flutter

A modern, sleek, and highly professional Personal Identity Card mobile and web application built with Flutter.

## 🌟 Features
- **Gradient Header Banner**: Contemporary indigo gradient header with geometric background accents.
- **Profile Avatar**: Dual glowing border ring frame with a verified security checkmark badge.
- **Role Badge**: Software Development role pill tag.
- **Stat Cards**: Interactive, color-tinted micro-cards for **Age (20 Years)**, **ID No. (#079)**, and **Blood Group (O+)**.
- **Contact Details**: Dedicated location and email cards.
- **Security Footer**: Official digital ID barcode footer graphic.

## 🚀 Getting Started

### Prerequisites
- Flutter SDK (^3.12.2 or later)
- Dart SDK

### Installation & Running

```bash
# Clone the repository
git clone https://github.com/AtharvaGahine11/Personal-Identity-Card-using-Flutter.git

# Navigate to project folder
cd Personal-Identity-Card-using-Flutter

# Fetch dependencies
flutter pub get

# Run on Web Server
flutter run -d web-server --web-port=8080
```
